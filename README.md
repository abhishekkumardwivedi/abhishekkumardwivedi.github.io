# abhishekkumardwivedi.github.io

Personal profile and technical article site for Abhishek Kumar Dwivedi, built with Astro Starlight and published through GitHub Pages.

## Local development

```sh
npm install
npm run dev
```

## Publish an article

Add a Markdown file under `src/content/docs/articles/` and push to `main`. The GitHub Pages workflow builds and publishes the site automatically.
